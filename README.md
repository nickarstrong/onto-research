# onto-research (retired)

This repository held ONTO's research materials from January to July 2026: the prompt-layer period (reports, the ONTO-Bench set,
paper drafts, a scorer) and early laboratory notes. It is no longer maintained.

Its history is kept as published, as the record of the stages ONTO went through. The current files of that period were removed
from the working tree on 2026-10-10; every one of them stays in the history of this repository.

- Published documents, with versions and corrections: **[ontostandard.org/archive](https://ontostandard.org/archive/)**

- The paper drafts and ONTO-Bench of January 2026: [ONTO:2601.0001](https://ontostandard.org/archive/2601.0001/)
- How ONTO teaches and checks a model today: [ONTO:2610.0007](https://ontostandard.org/archive/2610.0007/)
